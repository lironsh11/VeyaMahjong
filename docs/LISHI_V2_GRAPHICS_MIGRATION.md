# LiShi Mahjong Graphics Refresh v2: migration and QA

Graphics-only migration (2026-10-18). Gameplay rules, levels, save schema and keys, theme ids,
ads/IAP, translations and audio are unchanged. Content validator: 150/150 levels, 300/300
generated, 60/60 daily boards. Tests: 91 passed (84 existing + 7 new in `tests/test_art.gd`).

## Re-running the import

```bash
godot --headless --path . -s res://tools/import_lishi_v2.gd -- "<path>/LiShi_Mahjong_Graphics_Refresh_v2"
godot --headless --path . --import
```

The tool is deterministic and writes only `res://art/lishi_v2/` plus `MANIFEST.json` (every file
copied, generated, repaired or placeholder, with the reason). Not imported: `00_previews`,
`00_sources`, `06_marketing`, `03_ui/illustrated_samples` (reference only, some with baked
English), SVGs, tile backs (the game draws no tile backs) and the alternate illustrated icons.

Code: `ContentService` (lookups and mapping tables), `UITheme` (theme types), `UIKit` (tabs,
chips), `TileView`/`BoardView` (overlay nodes, 96/192 atlases), `ModalDialog` (Dialog panel),
`WorldMapScreen`, `BloomScreen`, `BootScreen`, `HomeScreen`, `DailyScreen`, `SettingsScreen`,
`ShopScreen`, `CollectionScreen`. Debug tour: `--bloom-all` mode and a "selected" shot.

Removed (now unreferenced; still in git history): `assets/veya/{tiles, backgrounds, ui/buttons,
ui/components, ui/icons}`, `branding/lishi_logo_*`, and the 13 decorations replaced by props.
Kept: audio, fonts, effect atlases, `ui/rewards`, owner app icons and 13 legacy decorations.

### Mapping decisions

- **Tile themes** (ids are save keys, unchanged): classic -> Sakura Premium (cream, the pack's
  gameplay default), sakura -> Jade Garden, ocean -> Pearl Ocean, nocturne -> Moonlit Lilac.
  One table: `ContentService.TILE_THEME_ART`.
- **Tile geometry is unchanged.** The pack's faces are 192x256 and not uniformly framed (body
  height varies ~7%). The import fits each face's opaque bounds onto the board's existing tile
  body (`BoardView.BODY`, `BoardFit.ASPECT`), so hit-testing, layout and the level tools'
  tile-size guarantees are untouched. `test_atlas_body_matches_board_view` pins this.
- **Backgrounds**: Aurora home/journey/gameplay art per screen kind; Crystal Nocturne uses its one
  night illustration; Pearl Coast keeps the pack's *legacy* illustration. Daily and Settings use
  Aurora art (Daily used Pearl Coast before). Gameplay and Bloom use the pack's pre-blurred
  boards (no shaders). Low profile uses the 540x960 sets, with pre-blurred 540x960 boards
  derived at import.
- **Bloom**: ids, order, unlock rules, tap stories and names are unchanged (`sprite` still keys
  the translations). Aurora Garden discoveries were re-anchored for the new art. Bloom now shows
  the world art pre-blurred so discoveries read as the sharp focal objects; with the sharp art
  they disappeared into the detailed scenery. One word to revert: `"bloom"` -> `"world"` in
  `BloomScreen.build_background`.
- **Selected/hint**: the pack rings are thin at phone tile sizes (~2 px), so the face also takes a
  light tint (gold = selected, jade = hint) in addition to the overlay and the existing lift.

## Pack defects fixed at import (listed in MANIFEST.json "repaired")

- **Five tile faces had the wrong pip count, in all four themes:** bamboo 5 (showed 2 + a
  flower), bamboo 6 (showed 4, same as bamboo 4), bamboo 8 (showed 7, same as bamboo 7),
  circle 7 (showed 5, same as circle 5), circle 8 (showed 9, identical to circle 9). With the
  identical-tiles-only rule these were unplayable. Rebuilt from the pack's own pips on the same
  face: bamboo 5 = 2-1-2, bamboo 6 = 3x2, bamboo 8 = 4x2, circle 7 = 3 diagonal + 4 red,
  circle 8 = 2x4. An artist should still redraw these five (traditional bamboo 8 is an M/W shape).
- `pink_flower_bush` carried a neighbouring sprite's gold pagoda finial; removed.

## Placeholders for pieces the pack lacks (MANIFEST.json "placeholders")

- Rose buttons (Restart confirm, Reset progress): hue-shifted from the pack's violet buttons.
- Switch knobs: the pack's switches are plain pills, so on/off was colour-only. An ivory knob with
  a gold rim was added (right = on).

## Not covered by the pack (still legacy or flat)

- **Pearl Coast world**: background (the pack's own legacy file) and all 10 of its Bloom
  discoveries stay flat-vector, so that world is at least consistent with itself.
- **Bloom objects with no matching prop** (legacy flat art): butterfly (Aurora + Nocturne),
  crystal cluster, drifting petals and sea grass (Nocturne). New props for these, or new
  translation keys if different objects are wanted, are needed.
- Unused new props (imported, not placed, since adding discoveries would change progression):
  bamboo_cluster, bamboo_fence, bamboo_fountain_top/bottom, bonsai_pot, flower_wheelbarrow,
  garden_bench, garden_signpost, garden_watering_bucket, hanging_lantern_paper/square,
  lantern_house, moon_gate, potted_lotus_vase, stone_cat, treasure_chest, wisteria_arch.
- Effects (match sparkle, gold twinkle, petal pop, ripple) and reward art (LiShi Light, flower):
  legacy.
- Round icon buttons, sliders, option buttons, popups: flat theme styles (no pack sprite).
- Weak pack icons worth redrawing: settings (a plain ring, not a gear), daily/calendar,
  collection and camera (blank shapes), info (blank disc), warning (no "!").
- The four tile themes are colour grades of one design; Classic and Sakura (jade) look close.

## App icon

The owner chose the pack's 發-tile icon. The pack's own exports of it are not usable as-is (the
iOS/Play icon is a different, sakura-tile design; the Android adaptive foreground is the framed
icon shrunk inside the canvas), so the full set is regenerated by `tools/make_app_icons.gd` from
the largest copy of the art (`00_sources/branding_master.png`, ~331 px). Details, sizes and
limits: docs/BRANDING.md. The import tool no longer copies the pack's icon exports.
