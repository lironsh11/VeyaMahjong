### Full description (829/4000)
```text
LiShi Mahjong は、ゆったり楽しめるクラシックな麻雀ソリティアです。そろえて。咲かせて。ほっとひと息。

取れる状態の同じ牌を2枚ずつ選んで、盤面を少しずつ片づけていきましょう。昔ながらの麻雀ソリティアで、牌を線でつなぐゲームや、3つそろえるゲームではありません。

【3つの世界に、手作りの150レベル】
オーロラガーデン、パールコースト、クリスタルノクターン。イラストで描かれた3つの世界を旅しましょう。牌の配置はすべて手作りです。

【毎日無料のデイリーパズル】
毎日、新しいデイリーパズルが遊べます。オフラインでも大丈夫です。遊べなかった日があっても心配いりません。過去30日分のパズルはあとから遊べて、連続記録もありません。デイリーチャレンジは、気が向いたときだけどうぞ。

【あなたの世界が花開く】
新しいレベルをクリアするたびに「LiShiの光」がひとつ手に入ります。光が5つ集まるごとに、イラストの世界に新しい飾りや発見が現れます。LiShi Bloom の発見は全部で30種類です。

【自分のペースで】
• ヒント、戻す（無制限）、シャッフルはいつでも無料
• 手詰まりになったら、残りの牌を無料でシャッフル。クリアできる所まで戻ることもできます
• 制限時間なし、ライフやスタミナもなし
• オフラインですべて遊べて、アカウント登録も不要
• プレイして解放できる4つの牌のテーマ：クラシック、さくら、オーシャン、ノクターン
• 実際に操作しながら覚えられるチュートリアル付き

【見やすく、遊びやすく】
• 大きな牌、ハイコントラスト
• 動きを減らす、取れない牌を暗く
• 音量の調整、バイブレーションのオフ

対応言語：日本語、英語、韓国語、ドイツ語、フランス語、スペイン語、ポルトガル語（ブラジル）、繁体字中国語、ヘブライ語、ロシア語

ひと息つきたいときに、牌をいくつかそろえて、あなたの世界を咲かせてみませんか。
```

## Notes for native reviewer

- App name "LiShi Mahjong: 麻雀ソリティア": "上海" is the more common Japanese search term for this genre but may be a trademark; it was deliberately left out. "四川省" was also avoided because it refers to a tile-connect game.
- "取れる状態の同じ牌" is used for "free tiles"; check it reads naturally and matches the tutorial wording.
- Tagline and all feature names (デイリーパズル, デイリーチャレンジ, 戻す, 大きな牌, 取れない牌を暗く, LiShiの光, world names) were copied from the in-game `ja.json`; keep them in sync if the game text changes.
- "ライフやスタミナもなし" renders "no lives/energy"; confirm スタミナ is the natural term.
- "牌を線でつなぐゲーム" describes tile-connect games without naming any title.
- Keywords: 花 and 庭 are short and cheap in bytes; replace them if better search terms exist. Each Japanese character costs 3 bytes.
- Rename: the game is now "LiShi Mahjong" (features "LiShi Bloom" and the LiShi Light term). The in-game translations use the same names.
- Rule change: every tile, including Flowers and Seasons, now matches only an identical tile. The old sentence saying any Flower matches any Flower (and any Season any Season) was removed, so the listing only says to match pairs of identical free tiles. Do not add it back. The in-game tutorial (`tut_step_bonus`) already teaches the identical-tiles rule.
