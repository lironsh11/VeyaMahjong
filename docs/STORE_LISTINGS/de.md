## Notes for native reviewer

- The listing uses "du", matching the in-game German text ("Du bist bereit!"). Switch to "Sie" consistently if the store voice should be more formal for older players.
- "Stufe/Stufen" is used for "level" because the game uses it ("Stufe", "Stufen geschafft"); many German store listings say "Level" instead – decide which reads better.
- Tagline, Tagesrätsel, Tägliche Aufgaben, Tipp/Zurück/Mischen, accessibility option names, Veya-Licht, Stein-Design and world names come from the in-game `de.json`.
- "kein Verbindungsspiel" is meant as "not a tile-connect game" – check it is understood.
- Apple subtitle "Entspannt Steinpaare finden" is a little telegraphic; alternative: "Ruhiges Steine-Legespiel" (24).
- "Solitär" vs. "Solitaire": German players search for both; keyword space did not allow both.
