The script `build_assets.py` generates most original artwork, audio, screen comps and Mahjong demo layouts. Requires Python with Pillow, fontTools, cairosvg, numpy, ffmpeg and font files available in your environment for outlining glyphs. Those font files are **not** redistributed. Generated reference moodboards are separate conversation artifacts. Running the script uses hard-coded `/mnt/data/veya_work` output paths; change `BASE` before rerunning elsewhere. Stages can be run by importing the module and calling `stage_worlds`, `stage_tiles`, `stage_brand_ui`, `stage_decor_fx`, `stage_atlases`, `stage_audio`, `stage_levels`, `stage_previews`, `finalize_pack`.
